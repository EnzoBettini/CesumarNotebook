35- 
a)Calloc é uma função para alocação de memoria, que limpa o bloco de memoria ser alocado
b)Malloc é um função para alocação de memoria, que não limpa seu bloco a ser alocado
c)Realloc é uma função para realocar a memória necessaria, tanto para menos quanto para mais

36-free serve para liberarmos a memoria após alocação pois caso não ocorra a liberação correta, o bloco de memoria fica travado até a reinicialização
sintaxe-> free(variavel_para_liberar);

37- a alocação dinâmica permite o uso eficiente e compacto da memoria, evitando alocação extra de espaço que não será utilizado

38-Quando não hám memoria disponivel o malloc ou calloc retorna NULL, não alocando a memória, podendo parar o programa ali

39- para um calloc utilizamos a sintaxe vetor=calloc(tam, tamAloc) onde:
vetor -> ponteiro a receber a alocação
tam-> quanto de tamanho vamos querer alocar
tamAloc -> tipo/tamanho em bytes da memoria alocada em cada espaço do vetor

40- para um malloc utilizamos a sintaxe vetor=malloc(tam*tamAloc) onde:
vetor -> ponteiro a receber a alocação
tam-> quanto de tamanho vamos querer alocar
tamAloc -> tipo/tamanho em bytes da memoria alocada em cada espaço do vetor

41- podemos usar malloc quando precisamos de uma alocação de memoria mais agíl, pois como ele não "limpa" o bloco de memoria a ser alocado, acaba sendo uma alocação mais veloz, ja o calloc utilizamos quando precisamos a memória com 0

42-Retorna seu estado, caso tenha sido corretamente alocado, retorna o valor do seu primeiro elemento do ponteiro. Caso não seja corretamente alocada, retorna NULL

43-Depende da quantidade de memória alocada, exemplo, se for 5*sizeof(int) o retorno sera 20 bytes

44-O bloco alocado pelo malloc pode conter lixo pois ele usa espaços da memoria que ja foram utilizados por alguem, e esses programas liberaram aquele espaço mas o lixo ficou la
