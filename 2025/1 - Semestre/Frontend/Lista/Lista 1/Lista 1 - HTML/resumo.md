1. <header>
   Atributos comuns: Não há atributos específicos usados aqui, mas podem ser adicionados como class, id, etc.

2. <main>
   Atributos comuns: class, id.

3. <div>
   Atributos comuns: class, id, style, data-*.

4. <h1>, <h2>
   Atributos comuns: class, id, style.

5. <ul>
   Atributos comuns: class, id, style.

6. <ol>
   Atributos comuns: class, id, style, start (para definir o valor inicial da lista).

7. <li>
   Atributos comuns: class, id, style.

8. <table>
   Atributos comuns: class, id, style, border, cellspacing, cellpadding.

9. <thead>
   Atributos comuns: class, id, style.

10. <tbody>
    Atributos comuns: class, id, style.

11. <tr>
    Atributos comuns: class, id, style.

12. <th>
    Atributos comuns: class, id, style, scope (define se a célula é um cabeçalho de linha, coluna ou grupo de colunas).

13. <td>
    Atributos comuns: class, id, style, colspan (define o número de colunas a serem mescladas), rowspan (define o número de linhas a serem mescladas).

14. <form>
    Atributos comuns: action (define o destino do formulário), method (define o método de envio, ex: GET, POST), name, id, class, enctype (define a codificação de dados, importante para upload de arquivos).

15. <input>
    Atributos comuns:

type="text": Campo de texto.

type="password": Campo de senha.

type="radio": Botão de seleção.

type="submit": Botão de envio.

placeholder: Texto que aparece dentro do campo até ser preenchido.

maxlength: Limita o número de caracteres.

name: Define o nome do campo (importante para envio de dados).

value: Define o valor do campo (usado especialmente em botões de seleção ou envio).

checked: Para marcar um botão de seleção ou caixa de seleção (não utilizado no código, mas aplicável a radio e checkbox).

disabled: Torna o campo desabilitado.

16. <textarea>
    Atributos comuns:

rows: Número de linhas visíveis.

cols: Número de colunas visíveis.

maxlength: Limita o número de caracteres.

placeholder: Texto que aparece até o campo ser preenchido.

name: Nome do campo.

resize: nome -> em CSS limita o tamanho e nao deixa com que o usuario altere o tamanho

17. <select>
    Atributos comuns:

name: Nome do campo.

id: Identificador único.

form: Associa a um formulário específico (não utilizado no código).

size: Define quantas opções são exibidas.

multiple: Permite selecionar várias opções.

18. <option>
    Atributos comuns:

value: Define o valor enviado quando a opção é selecionada.

selected: Marca uma opção como selecionada por padrão.

19. <button>
    Atributos comuns:

onclick: Define a ação executada ao clicar no botão.

type: Pode ser button, submit, reset.

disabled: Torna o botão desabilitado.

20. <a>
    Atributos comuns:

href: Define o destino do link.

target: Define onde o link será aberto, ex: \_blank (nova aba).

rel: Define o relacionamento entre o link e o destino, como noopener, noreferrer.

21. <img>
    Atributos comuns:

src: Define o caminho da imagem.

alt: Texto alternativo, útil para acessibilidade e SEO.

width, height: Define as dimensões da imagem.

title: Define um título que aparece ao passar o mouse.

22. <article>
    Atributos comuns: class, id, style.

23. <nav>
    Atributos comuns: class, id, style.

24. <aside>
    Atributos comuns: class, id, style.

25. <section>
    Atributos comuns: class, id, style.

26. <footer>
    Atributos comuns: class, id, style.
