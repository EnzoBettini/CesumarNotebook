Promoção de Funcionário (Operador $set)

Solicitação: O funcionário "Daniel Farias" foi promovido! O RH solicitou a alteração de seu cargo para "Cientista de Dados" e seu salário para 7800.00.
db.funcionarios.updateOne(
  { nome: "Daniel Farias" }, // Filtro para encontrar o documento
  { 
    $set: { 
      cargo: "Cientista de Dados", 
      salario: 7800.00 
    } 
  } // Ação de atualização
)

Vamos consultar o registro do Daniel para ver se a promoção foi aplicada."

db.funcionarios.findOne({ nome: "Daniel Farias" })

A diretoria anunciou um reajuste de 10% no salário de todos os funcionários ativos. Aplique este aumento.
// Usamos um pipeline de atualização para calcular o novo valor baseado no valor antigo.
db.funcionarios.updateMany(
  { ativo: true },
  [ { $set: { salario: { $round: [ { $multiply: ["$salario", 1.10] }, 2 ] } } } ]
)

Encontre todos os funcionários com mais de 30 anos.
db.funcionarios.find({ idade: { $gt: 30 } })

Encontre todos os funcionários com salário entre R$ 7.000 e R$ 9.000.
db.funcionarios.find({ salario: { $gte: 7000, $lte: 9000 } })

Encontre todos os funcionários cujo nome começa com a letra "A".
db.funcionarios.find({ nome: { $regex: /^A/ } })


Encontre todos os funcionários que têm "Desenvolvedor" no cargo.
db.funcionarios.find({ cargo: { $regex: /Desenvolvedor/i } })


Encontre todos os funcionários que possuem a habilidade "React".
db.funcionarios.find({ habilidades: "React" })

Encontre todos os funcionários que possuem as habilidades "AWS" e "Python".
db.funcionarios.find({ habilidades: { $all: ["AWS", "Python"] } })

Encontre o funcionário cujo e-mail é "carla.dias@empresa.com".
db.funcionarios.find({ "contato.email": "carla.dias@empresa.com" })


Encontre todos os funcionários do departamento de "Tecnologia" que também estão com o status ativo.
db.funcionarios.find({ departamento: "Tecnologia", ativo: true })

Encontre todos os funcionários que são do departamento de "RH" OU do departamento de "Projetos".
db.funcionarios.find({
  $or: [
    { departamento: "RH" },
    { departamento: "Projetos" }
  ]
})


Encontre todos os funcionários do departamento de "Tecnologia" que OU têm mais de 30 anos OU possuem a habilidade "AWS".
db.funcionarios.find({
  departamento: "Tecnologia", // Condição AND
  $or: [ // Condições OR
    { idade: { $gt: 30 } },
    { habilidades: "AWS" }
  ]
})


Liste todos os funcionários, mas mostre apenas o nome e o cargo de cada um.
db.funcionarios.find(
  {}, // O primeiro {} vazio significa "sem filtro", ou seja, todos os documentos.
  { nome: 1, cargo: 1, _id: 0 } // O segundo {} é a projeção.
)


Liste todos os funcionários ordenados por salário, do menor para o maior.
db.funcionarios.find().sort({ salario: 1 })

Liste os funcionários do departamento de "Tecnologia" ordenados por data de contratação, do mais recente para o mais antigo.
db.funcionarios.find({ departamento: "Tecnologia" }).sort({ data_contratacao: -1 })

Liste apenas os 3 funcionários com os maiores salários.
db.funcionarios.find().sort({ salario: -1 }).limit(3)

Encontre todos os funcionários que possuem um número de telefone cadastrado.
db.funcionarios.find({ "contato.telefone": { $exists: true } })

Encontre todos os funcionários cujo campo salario é do tipo double (número de ponto flutuante).
db.funcionarios.find({ salario: { $type: "double" } })
